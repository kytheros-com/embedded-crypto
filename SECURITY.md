# Security Policy

## Project status

Embedded Crypto is in early development. No release is currently
supported for production use, and the software has not been
independently audited.

Do not rely on this project to protect sensitive or operational data.

## Reporting a vulnerability

Do not report suspected vulnerabilities through a public GitHub issue.

Send reports privately to <jason@kytheros.com>. Include enough detail
to reproduce and evaluate the issue, but do not include proprietary or
confidential information.

Because the project is not currently accepting external code
contributions, please do not include patches or proposed source code
unless explicitly requested.
