# Contributing

This project is not currently accepting external code contributions.

Please do not submit pull requests, patches, proposed implementations,
or code excerpts through issues, email, or other channels. Unsolicited
code submissions may be closed without review.

Bug reports and technical observations are welcome. Reports should
describe the observed behavior, reproduction conditions, and relevant
test inputs without including proprietary, confidential, or
security-sensitive information.

Do not use a public issue to report a suspected security vulnerability.
Follow the instructions in [SECURITY.md](SECURITY.md) instead.

This contribution policy may change in the future.
